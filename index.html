📖 About Project

AI Smart Civic Connect is developed during Industry Training at Indradeep Information Technology Pvt Ltd. It is an AI Based Smart City Complaint System where citizens can file complaints with Live GPS and Image proof using Gemini AI and Chatbase AI.

🛠️ Technology Used

Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
Backend: Python Flask (app.py)
AI & Chatbot: Gemini AI, Chatbase AI
Firebase: Firebase Authentication, Firestore, Storage, Email Verification
Features: Live GPS Location, Image Upload, Complaint Status Tracking, 3 Dashboards
Analytics: Chart.js
Tools: VS Code, Git & GitHub
