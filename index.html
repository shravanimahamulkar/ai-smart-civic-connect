📖 About Project

This project has been developed as a part of the Inplant Training Program 2026. The main objective of this project is to provide students with real-world software development experience. The project is built with a modern, responsive and user-friendly design, which works perfectly on both mobile and desktop devices. It is an AI Based Citizen Complaint & Smart City Management System powered by Gemini AI and Flask.

🎯 Objectives

  • To gain practical knowledge of industrial training
  • To enhance Web Development skills (HTML, CSS, JavaScript, Flask)
  • To implement AI for real-time problem solving
  • To create complete project documentation and deployment

🛠️ Technology Stack

Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
Backend: Python Flask (app.py)
AI Integration: Gemini AI, Chatbase AI
Database & Tools: Firebase, Git & GitHub, VS Code
