📖 About Project

AI Smart Civic Connect is developed as a part of the Inplant Training Program 2026. It is an AI Based Citizen Complaint & Smart City Management System that helps citizens to register complaints regarding Road, Water, and Street Light issues with Live GPS and Image proof. The system uses Artificial Intelligence to automatically detect complaint categories and provides 3 different dashboards for better management. The project is fully responsive and works on both mobile and desktop.

🎯 Objectives

  • To gain practical knowledge of industrial software development
  • To build a real-time Smart City complaint solution
  • To integrate AI Chatbot for 24/7 citizen support
  • To implement secure authentication and data storage

🛠️ Technology Stack Used

1. Frontend: HTML5, CSS3, Bootstrap 5.3, JavaScript, Poppins Font
2. Backend: Python Flask (app.py), Flask-CORS
3. AI & Chatbot: Gemini AI API (Auto Category), Chatbase AI, Custom JS Chatbot Logic
4. Firebase: Firebase Authentication, Firestore Database, Firebase Storage, Email Verification
5. Features: Live GPS Location API, Image Upload & Preview, Complaint Status Tracking, 3 Dashboards (User, Officer, Admin)
6. Analytics: Chart.js for Reports & Graphs
7. Tools: VS Code, Git, GitHub, GitHub Pages Deployment
